# API

All product routes live under '/api/v1'. OpenAPI is generated by FastAPI.

Resource groups are authentication, assets, watermark profiles, distributions, verifications, collections, searches, scans, benchmarks, reports, jobs, settings, and health/readiness.

Errors use a stable envelope containing 'code', 'message', optional 'field_errors', and 'correlation_id'. Long operations return a job with queued/running/completed/failed/cancelled state, stage, progress, timestamps, safe failure information, and a result link.

Authentication uses an HTTP-only opaque session cookie. State-changing cookie-authenticated requests require the matching CSRF header. Object identifiers never imply authorization; every query is scoped to the active user or an explicit administrative role.

Binary downloads are streamed only after authorization and never expose MinIO keys or filesystem paths.
