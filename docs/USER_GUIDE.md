# User Guide

1. Sign in with an account created by the seed or registration workflow.
2. Protect Image: upload a supported image, review safe metadata, choose visible/invisible settings and a robustness profile, generate, inspect quality evidence, and download.
3. Asset Details: review fingerprints, outputs, distribution copies, verification history, benchmarks, and search matches.
4. Distribution Copy: provide an optional label/reference stored only in the database, generate a new opaque tokenized copy, and download it.
5. Verify Image: upload a suspected image and inspect exact, watermark, similarity, local-feature, and provenance evidence separately.
6. Collections: create a collection, add images or a safe ZIP, wait for indexing, and search with an asset or new query.
7. Source Scanner: submit only public URLs you are authorized to scan. Unsupported or blocked sources should be downloaded manually and verified.
8. Robustness Lab: select a profile, run transformations, inspect measured survival/quality evidence, and export results.
9. Reports: export HTML, PDF, or JSON evidence and retain the explicit limitations with any shared report.
